# DailyHabits User Story

## Inicio de Sesión / Registro
1. Registro de aplicación: Un usuario puede registrarse ingresando su nombre de usuario, correo electrónico y contraseña, luego haciendo clic en el botón de "Registrar".
2. Inicio de sesión de la aplicación: Un usuario puede acceder a la app ingresando su correo electrónico y su contraseña, y luego pulsando el botón de "Iniciar Sesión".
3. Retroalimentación de error en el registro e inicio de sesión: Un usuario recibirá un mensaje si intenta hacer clic en el botón Registrarse sin ingresar sus datos. Si el usuario ingresa el nombre de usuario o la contraseña incorrectos, recibirá un mensaje indicando que el intento de inicio de sesión fue fallido.
4. Almacenar datos del usuario: Los detalles del usuario se guardarán en el almacenamiento local para que los datos persistan entre las sesiones de la aplicación.
5. Como nuevo usuario, quiero elegir entre hábitos prediseñados al registrarme para empezar a usar la app más rápido.

## Pantalla de Inicio
- Como usuario, quiero ver una lista de mis hábitos pendientes para saber qué actividades me faltan realizar hoy.
- Como usuario, quiero deslizar un hábito hacia la izquierda para marcarlo como completado y que pase a la lista de hechos.
- Como usuario, quiero deslizar un hábito completado hacia la derecha para poder deshacer el cambio si me equivoqué.
- Como usuario, quiero acceder a la pantalla de configurar hábitos desde el botón "+" para poder agregar nuevos hábitos.

## Configurar Hábito
- Como usuario, quiero agregar un nuevo hábito ingresando su nombre para poder empezar a rastrearlo.
- Como usuario, quiero asignarle un color a cada hábito para poder identificarlo visualmente en la lista.
- Como usuario, quiero volver a la pantalla de inicio usando la flecha superior izquierda sin perder los cambios que hice.

## Persistencia de Datos
- Como usuario, quiero que mis datos de inicio de sesión persistan entre sesiones para no tener que volver a ingresarlos cada vez.
- Como usuario, quiero que mi información de perfil y mis hábitos guardados persistan entre sesiones para no perder mi información al cerrar la app.

## Menú de Configuración
- Como usuario, quiero poder tener un menú de configuración para poder acceder desde cualquier pantalla para poder ajustar mis preferencias a mi gusto.

## Pantalla de Configuración
- Como usuario, quiero guardar mi información personal (nombre, nombre de usuario, edad) para que aparezca reflejada en la parte superior de la app.
- Como usuario, quiero ver un informe de mi progreso semanal de hábitos para entender qué tan bien los estoy cumpliendo.
- Como usuario, quiero habilitar notificaciones para hábitos específicos y elegir cuándo recibirlas para que me recuerden solo lo que me interesa.
